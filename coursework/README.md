# Coursework & Academic Practical Exercises (`coursework/`)

This directory contains standalone academic coursework, lab activities, and practical demonstrations completed as part of the **BSc Information Technology** curriculum at Eduvos East London Campus.

---

## 🎯 Purpose

These files are isolated from the main production application architecture of the **All I Luxe** e-commerce marketplace to maintain clean separation of concerns while preserving academic submission history and coursework artifacts.

---

## 📂 File Inventory

| File | Activity / Topic | Description |
| :--- | :--- | :--- |
| `week6Form.html` | Week 6 Class Activity | HTML form demonstrating data capture (Username, Email, Password) with multipart encoding. |
| `week6.php` | Week 6 Class Activity | Backend handler demonstrating local XAMPP MySQL database connection (`localhost`, `root`) and SQL `INSERT` execution. |

---

## 🧪 Testing Coursework Scripts Locally

1. Ensure **Apache** and **MySQL** are running via the XAMPP Control Panel.
2. Ensure a database named `users` with table `users (name, email, password)` exists in your local MySQL instance.
3. Open `http://localhost/All-I-Luxe-E-Commerce-Platform/coursework/week6Form.html` in your browser.
4. Fill in test values and submit the form to verify data insertion into your local database.
